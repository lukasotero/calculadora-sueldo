# Contribuir

Gracias por ayudar a que los cálculos salariales sean más claros.

1. Creá una rama descriptiva y cambios pequeños.
2. Para reglas legales, citá una fuente oficial, su vigencia y la fecha de consulta.
3. Agregá pruebas para casos normales, topes y cambios de escala.
4. No incluyas recibos reales ni datos personales. Usá únicamente fixtures ficticios.
5. Ejecutá `npm run check` antes de abrir el pull request.

Los reportes de errores normativos deben incluir período, resultado esperado, resultado obtenido y la fuente primaria que respalda la corrección.
